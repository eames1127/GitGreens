# GitGreens

Vue 3 + Vite + Tailwind single-page app that turns a GitHub user's public repos into a seasonal SVG garden.

Before working, read the guides in [docs/](docs/README.md):

- [docs/architecture.md](docs/architecture.md) — data flow, garden layout and which layer owns what
- [docs/conventions.md](docs/conventions.md) — code, styling and asset conventions
- [docs/workflow.md](docs/workflow.md) — branches, worktrees, checks, tests, definition of done

Commands:

- `npm run dev` / `npm run preview` — run the app
- `npm run lint`, `npm test`, `npm run build` — all three must pass (CI runs them on every PR)

Keep the docs in step with the code when architecture or conventions change.
